- **Desktop: set RAM to its rated speed (EXPO) in BIOS — not yet done, and sequencing matters.** New RAM installed after the surge; with no EXPO profile selected the board runs it at the JEDEC default (typically 4800 MT/s), well under the kit's rating. Check what it's actually running now: `sudo dmidecode -t memory | grep -E "Speed|Configured Memory Speed"` (`Configured` is the live speed, `Speed` is the SPD-rated one — if they differ, EXPO is off).
  **Order, and the reason for it:** EXPO is an overclock — it runs the memory controller out of JEDEC spec, so instability from EXPO is indistinguishable from instability from a surge-damaged board, the same trap the Curve Optimizer item below carries. So: (1) memtest at JEDEC default first — that's the run that clears the RAM and board; (2) only then enable EXPO in BIOS; (3) memtest again at EXPO. A failure appearing only in step 3 is EXPO's, not the board's — that separation is the whole point and is lost if EXPO goes on first.
  If step 3 fails, EXPO I is the fallback before giving up on rated speed, and on AM5 two-DIMM configs generally clock higher than four.
